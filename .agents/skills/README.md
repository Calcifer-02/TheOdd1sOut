# Навыки агента

> Переносимые инструкции TRIP: как выполняется операция и чем подтверждается
> результат. Шаблон несёт **порядок установки**, а не саму поставку.

## Почему каталог пуст

Навыки подключаются в **Gate 2 «Команда как инструмент»** и приходят вместе с
порцией методологии, в её каталоге `08_БИБЛИОТЕКА_ЗАГОТОВОК/НАВЫКИ/`.

Копия навыков в шаблоне удвоила бы одни и те же файлы: на Gate 2 те же
`SKILL.md` легли бы в `МЕТОДОЛОГИЯ/`, и в репозитории оказалось бы два
версионируемых набора. Расходятся они молча, а агент начинает работать
неизвестно по какому из них.

Поэтому здесь лежит порядок, проверка и замок отпечатков, а поставка приходит
порцией.

## Установка, когда порция пришла

```bash
node ИНСТРУМЕНТЫ/скрипты/навыки.mjs установить-из МЕТОДОЛОГИЯ/ДОКУМЕНТЫ/08_БИБЛИОТЕКА_ЗАГОТОВОК/НАВЫКИ
```

Одна команда делает то, что иначе делается руками и с ошибками:

| Что делает | Почему это не мелочь |
|---|---|
| раскладывает каждый навык каталогом первого уровня по полю `name` | у практик имя каталога-источника не совпадает с `name`; при копировании как есть агент навык не найдёт |
| переносит адаптеры сред, лежащие рядом с `SKILL.md` | без них навык теряет часть заявленной совместимости |
| переносит условия использования пакета практик | лицензия и уведомление обязаны идти вместе с пакетом |
| собирает замок отпечатков и реестр | без отпечатка правку установленной копии нечем обнаружить |
| отказывается перезаписать занятое имя другим содержимым | совпадение имён требует решения владельца, а не молчаливой замены |

Обёртка `ИНЖЕНЕРНЫЕ_ПРАКТИКИ/` в установку не переносится: она является
каноническим пакетом-источником, а не навыком.

## Проверка

```bash
node ИНСТРУМЕНТЫ/скрипты/навыки.mjs проверить
```

Пока порция не пришла, проверка сообщает, что навыки не установлены, и это не
находка. После установки она отвечает на четыре вопроса: у каждого каталога
есть `SKILL.md`, имя навыка совпадает с именем каталога, имена уникальны,
отпечаток совпадает с замком `ЗАМОК_НАВЫКОВ.json`.

Несовпадение отпечатка означает правку установленной копии в обход канона —
такая копия перестаёт получать исправления методологии. Порядок узаконивания
правки: изменение вносится в канон, оттуда приходит обновлённая поставка, и
только затем пересобираются замок и реестр.

```bash
node ИНСТРУМЕНТЫ/скрипты/навыки.mjs замок
node ИНСТРУМЕНТЫ/скрипты/навыки.mjs реестр
```

Состав установленного показывает собираемый файл `РЕЕСТР.md`: он не пишется
руками и сверяется проверкой с фактической установкой.

## Каталог среды агента

`.agents/skills/` — единственный версионируемый набор. Среда, читающая другой
каталог, получает копию:

```bash
node ИНСТРУМЕНТЫ/скрипты/навыки.mjs разложить .claude/skills
```

Каталог раскладки исключён из версионирования. Правится всегда `.agents/skills/`,
после чего раскладка пересобирается.

## Границы

- Навык объясняет порядок работы, но не заводит правило проекта.
- Навык не заменяет предметное средство: грамматикой и вердиктом владеет
  исполнитель, а не инструкция.
- Свидетельство инструмента не является решением человека: ревью и контрольную
  точку навык не проходит.
- Часть поставки помечена зрелостью `частично` и подтверждается вручную:
  зрелость навыка не выше наименее зрелой обязательной операции.
- Без основания `R-id`, решения, риска или `BUG-id` навык не изменяет проект и
  возвращает `ждёт решения`.
