>
> Если агент читает третий файл (`.cursorrules` и подобные) — туда копируется содержимое
> `AGENTS.md`, а не пишется отдельный свод.

@AGENTS.md

## Суть (если читать только этот абзац)

Русский язык без жаргона; идентификаторы (`R-XXX`, `AC-id`) — латиницей; имена — из
глоссария проекта. Один проект — один единый репозиторий; сгенерированное и ПДн не версонируется.
Один логический сдвиг — один коммит с отдельными типом и направлением
`тип(направление[/область]): описание` и ссылкой на требование;
значимое изменение — с фальсифицируемой проверкой в том же коммите. Состояние
JSON-сериализуемо, случайность — через явный генератор. Ответственность распределяется
по RACI, у каждого результата один `A`; агент не становится `A`. Замечания — только по
записанным правилам. Перед ответом — самопроверка
(трассировка, проверка, словарь, память).

Проектная часть свода в четырёх строках: средства из `.trip/tools` запускаются каждую
итерацию, а не упоминаются, и непройденное называется вместе с причиной; операция,
для которой есть навык, выполняется навыком; предметные имена берутся из
[глоссария](./docs/ПАКЕТ_АНАЛИТИКИ/ГЛОССАРИЙ.md) и недостающий термин заводится там же
тем же коммитом; устойчивый факт итерации ложится в [`MEMORY.md`](./MEMORY.md).

Полные правила — в [`AGENTS.md`](./AGENTS.md). Память проекта — в [`MEMORY.md`](./MEMORY.md).
