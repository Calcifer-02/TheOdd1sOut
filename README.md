## Структура репозитория

```text
src/         исходный код (back/, front/, shared/ — по потребности)
tests/       проверки
devops/      запуск и эксплуатация
docs/        аналитика: требования, решения, пакет артефактов
ux/          материалы интерфейса и эстетики
client/      материалы заказчика и демонстраций
МЕТОДОЛОГИЯ/ выданная порция методологии, только для чтения
ИНСТРУМЕНТЫ/ реестр и установка средств слоя B
.agents/     навыки агента: порядок установки переносимых инструкций
trip.json    политика проверок Git-следа; валидаторы — в trip/
```

Структура соответствует рекомендуемому профилю репозитория TRIP: каталог задаёт
дом артефакта и подсказывает направление изменения, но не подменяет направление,
объявленное в сообщении коммита.
