# Практические руководства TRIP

Раздел содержит короткие руководства. Обязательные правила определяются основными
артефактами и каталогами; здесь собраны только способы применения.

1. [Приоритеты и управление охватом](ПРИОРИТЕТЫ_И_ОХВАТ.md)
2. Требования и общение с заказчиком (подключается в Gate 1)
3. Разработка и архитектура (подключается в Gate 3)
4. Проверка и работа с дефектами (подключается в Gate 3)
5. Команда и работа с ИИ-агентами (подключается в Gate 2)
6. Маршрутизация усилия модели по цене ошибки (подключается в Gate 2)
7. Итерационный цикл с явным остатком (подключается в Gate 2)
8. Временный канал демонстрации прототипа (подключается в Gate 2)

Руководство не должно дублировать шаблон, каталог или обязательное правило. Новая практика
добавляется только в подходящее руководство; отдельный файл создаётся, если у него появился
самостоятельный проверяемый потребитель. Человеческая техника ведения работы
остаётся руководством; `SKILL.md` получает только выделенная из неё повторяемая
операция агента с результатом, границей полномочий и ближайшей проверкой.
