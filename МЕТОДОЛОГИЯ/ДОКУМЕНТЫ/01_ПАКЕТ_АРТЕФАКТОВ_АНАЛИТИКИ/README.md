# Пакет артефактов аналитики

Пакет сохраняет трассу от исходного запроса до проверяемого результата. Команда выбирает
только артефакты, у которых есть потребитель; пустые документы ради контрольной точки не
создаются.

## Состав

| Контур | Артефакты |
|---|---|
| Контекст проекта | устав, матрица стейкхолдеров, видение и границы, глоссарий проекта |
| Требования | черновые требования, реестр требований, пользовательские истории, сценарии использования, открытые вопросы |
| Риск и решения | единый реестр рисков с производной матрицей, записи архитектурных решений |
| Проверка | сценарий демонстрации, приёмочные тесты, тестовые сценарии |
| Особые входы | описание проекта и входной пакет наследованной системы |
| Дефекты | компактный реестр `BUG-id → R-id → AC-id/TC-id`; анализ влияния остаётся в графе и задаче исправления |
| Решения по стадиям | журнал контрольных точек: вердикты, из которых выводится стадия проекта |

Матрица трассируемости ведётся внутри
реестра требований (подключается в Gate 3): требование связывается с историей,
сценарием, архитектурным решением, реализацией и проверкой. Формулировка, состояние и класс
важности принадлежат реестру; связи реализации объявляются кодовыми якорями, а колонка
«Файл / модуль», матрица и граф строятся как производные представления. Отдельная карта
подтверждений не ведётся.

Доменные, технические, бизнесовые и командные угрозы входят в единый
реестр рисков (подключается в Gate 1); матрица оценки строится из него.
Отдельный реестр нежелательных явлений не нужен.

Обратная связь о продукте изменяет требования, риски и сценарии. Обратная связь о самой
методологии TRIP не является аналитическим артефактом проекта.

## Правила шаблонов

- YAML-frontmatter сохраняется: TRM использует его для импорта и каталога шаблонов.
- Видимый паспорт проекта не заполняется вручную, если дату, автора и версию можно получить
  из Git и TRM.

- Связи указываются устойчивыми идентификаторами и относительными ссылками.
- Артефакт обновляется в месте, которое уже является источником истины; параллельная таблица
  с теми же сущностями не создаётся.
