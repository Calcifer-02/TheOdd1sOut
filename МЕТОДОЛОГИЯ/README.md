# Gate 4. Демонстрация

**Контрольный вопрос:** Может ли заказчик самостоятельно попробовать и оценить решение?

**Минимальное свидетельство:** Воспроизводимая демонстрация, наблюдение заказчика и решение по обратной связи.

**Маршрут чтения:** [КАРТА_ОБЯЗАТЕЛЬНОГО_ЧТЕНИЯ.md](./КАРТА_ОБЯЗАТЕЛЬНОГО_ЧТЕНИЯ.md)

Каталог содержит только документы, впервые подключаемые в этой
контрольной точке. Ранее загруженные порции сохраняются. Наличие шаблона
не означает, что его нужно заполнять без фактической потребности.
Порция выдаётся после решения предыдущей точки и до работы, необходимой
для прохождения текущей.
