# Развёртывание TRIP Frontend Inspector из бандла выпуска

> Файл едет внутри `trip-frontend-inspector-bundle.tar.gz` из реестра пакетов
> репозитория. Внутри — производственный пакет, который собирает канонический
> `npm run package` репозитория (вместе с его манифестом и SBOM), плюс
> `ВЫПУСК.json` и этот порядок.

## Подъём службы

Нужен .NET Runtime (ASP.NET Core) 10. Из корня распакованного бандла:

```bash
tar -xzf trip-frontend-inspector-bundle.tar.gz -C frontend-inspector && cd frontend-inspector
dotnet FrontendInspector.Api.dll --serve-workbench
```

Служба отдаёт API и Vue Workbench на одном origin; режим hosting виден в
`/health`. Для opt-in браузерных проверок на машине должен стоять браузер
Playwright — порядок установки описан в репозитории средства
(`npm run browser:install`); статические проверки работают без него.

## Откуда берётся бандл

Реестр пакетов репозитория `TRIP/tooling/frontend-inspector`, generic-пакет
`trip-frontend-inspector`, закреплённая версия из замка средств проекта.
Доступ на чтение даёт токен развёртывания с единственным правом
`read_package_registry`; рядом с бандлом лежит отпечаток SHA-256. Состав
пакета и отпечатки отдельных файлов — во внутреннем манифесте
`trip.frontend-inspector.release-manifest/v1`.
