# Инструкции к средствам слоя B

> Пользовательские инструкции к средствам из [страховочных колёс](../training-wheels.json).
> Команда не имеет доступа к исходникам средств на внутреннем GitLab, поэтому
> инструкции продублированы сюда.

Это **копии**, а не канон. Источники — файлы выпусков (те же архивы, что
ставятся в `.trip/tools/`) и, где выпуск инструкции не несёт, репозитории
исходников. Копия обновляется при смене версии средства в страховочных колёсах — тем же
коммитом. Расхождение копии с поведением средства — повод обновить копию,
а не править её отдельно от выпуска.
