# Развёртывание TRIPWIRE из бандла выпуска

> Средство едет потребителю СОБРАННЫМ файлом `tripwire-any.tar.gz` из реестра
> пакетов репозитория, а не исходниками. Команде не нужна учётная запись на
> сервере исходников и не нужно клонировать репозиторий — только доступ на чтение
> реестра пакетов и Python на машине.

## Что внутри бандла

Переносимый bytecode-бандл (внутри только `.pyc`, ни одного `.py` ядра):

```text
tripwire/
  trip-wire            # launcher (POSIX): выбирает байткод под minor Python
  trip-wire.cmd        # launcher (Windows)
  tripwire-cp311.zip   # байткод под Python 3.11  (launcher берёт zip
  tripwire-cp312.zip   # байткод под Python 3.12   под версию интерпретатора
  tripwire-cp313.zip   # байткод под Python 3.13   на машине)
  ВЫПУСК.json          # версия, поддержанные minor, отпечаток состава
  README.md CHANGELOG.md THIRD_PARTY_NOTICES.md
```

**ОС значения не имеет** — байткод ядра OS-независим (ядро только stdlib, без
нативного кода). Нужен лишь **Python 3.11–3.13** на машине; launcher сам берёт
zip под установленный minor. Своя версия Python указывается `TRIPWIRE_PYTHON`.

## Откуда берётся бандл

Реестр пакетов репозитория `TRIP/tooling/tripwire`, generic-пакет `tripwire`,
закреплённая версия из замка средств проекта. Доступ на чтение даёт токен
развёртывания с единственным правом `read_package_registry`; рядом с бандлом
лежит отпечаток SHA-256.

```bash
BASE="$CI_API_V4_URL/projects/<project-id>/packages/generic/tripwire/<версия>"
curl -sSfL --header "PRIVATE-TOKEN: $DEPLOY_TOKEN" "$BASE/tripwire-any.tar.gz" -o tripwire-any.tar.gz
curl -sSfL --header "PRIVATE-TOKEN: $DEPLOY_TOKEN" "$BASE/tripwire-any.tar.gz.sha256" -o tripwire-any.tar.gz.sha256
sha256sum -c tripwire-any.tar.gz.sha256   # «скачалось» без сверки не отличимо от «скачалось не то»
tar -xzf tripwire-any.tar.gz
```

## Запуск

```bash
# сканирование цели -> конверт trip.sec-finding/v1 (коды выхода 0/2/3/1)
./tripwire/trip-wire scan <путь> --basis <R-id|BUG-id|risk>
```

Коды выхода пригодны к CI-гейту: `0` чисто, `2` есть TRUE_POSITIVE (валить сборку),
`3` partial/needs_review, `1` ошибка. Вердикт детерминирован на хосте — место
средства у гейта (Gate 6), а не в еженедельной рассылке.

Встраивание в поток TRIP команды: `--sarif` в code-scanning, `--emit-defects` —
снимок `trip.defect-state/v1` в свой trip-bug-loop, `--trace` — привязка к
требованию. Полный список ключей — `./tripwire/trip-wire scan -h`.

## Многоязычие (опционально)

Ядро (`scan`) — только stdlib и офлайн. Разбор Java/C#/TS/JS/Vue включается
установкой extra в тот же Python, из которого запускается launcher:

```bash
pip install "tree-sitter>=0.25,<0.27" "tree-sitter-language-pack>=1.15,<2"
```

pip сам подберёт нативное колесо под ОС. Без extra многоязычный анализатор мягко
недоступен — ядро работает как прежде (офлайн-инвариант цел).
