# Развёртывание TRIP Backend Inspector из бандла выпуска

> Файл едет внутри `trip-backend-inspector-bundle.tar.gz` из реестра пакетов
> репозитория. Бандл самодостаточен: исходники службы и доступ к серверу
> исходников для развёртывания не нужны.

## Состав бандла

| Что | Зачем |
|---|---|
| `app/` | опубликованное приложение с встроенным Human Workbench (framework-dependent, ASP.NET Core 10) |
| `Dockerfile.release` | образ службы из готового приложения, без исходников |
| `compose.release.yaml` | подъём службы одной командой |
| `ВЫПУСК.json` | версия, состав и происхождение бандла |

## Подъём службы

```bash
tar -xzf trip-backend-inspector-bundle.tar.gz -C backend-inspector && cd backend-inspector
BACKEND_INSPECTOR_SOURCES=<каталог источников> docker compose -f compose.release.yaml up --build -d
```

Служба и Workbench — `http://127.0.0.1:8080`, здоровье — `/health/live`.
Инспектируемые OpenAPI-документы кладутся в каталог источников; свидетельства
пишутся в volume `envelopes` и переживают пересоздание контейнера.

Без docker (нужен ASP.NET Core Runtime 10):

```bash
BACKEND_INSPECTOR_SOURCE_ROOT=<каталог источников> \
BACKEND_INSPECTOR_EVIDENCE_ROOT=<каталог свидетельств> \
dotnet app/Trip.BackendInspector.Api.dll
```

## Откуда берётся бандл

Реестр пакетов репозитория `TRIP/tooling/backend-inspector`, generic-пакет
`trip-backend-inspector`, закреплённая версия из замка средств проекта.
Доступ на чтение даёт токен развёртывания с единственным правом
`read_package_registry`; рядом с бандлом лежит отпечаток SHA-256.
